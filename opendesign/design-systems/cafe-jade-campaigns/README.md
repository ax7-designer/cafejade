# Café Jade Campaigns

Reusable campaign system extracted from the production website, its official logo files, and the supplied sports-poster typography reference.

Sources: `index.html`, `assets/images/brand/`, production Café Jade copy, and the supplied reference image. The reference informs type hierarchy only; its athletes, composition, and monochrome treatment are not copied.

- `tokens/colors_and_type.css`: canonical campaign tokens.
- `brand/voice-and-tone.md`: campaign voice rules.
- `brand/style-notes.md`: visual foundations and reference-type translation.
- `assets/logos/`: copied official brand marks.
