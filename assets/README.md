# Imagenes del prototipo

Coloca aqui las imagenes reales de Cafe Jade.

Estructura sugerida:

- `hero/`: fachada, terraza, ambiente principal.
- `menu/`: platillos, cafe, bebidas y postres.
- `events/`: musica en vivo, noches culturales, eventos privados.
- `brand/`: logotipo, detalles graficos, texturas o elementos de marca.

Usar nombres descriptivos ayuda a mantener el sitio facil de actualizar, por ejemplo:

- `hero/terraza-noche-cafe-jade.jpg`
- `menu/cafe-especialidad-taza.jpg`
- `events/musica-en-vivo-palenque.jpg`
