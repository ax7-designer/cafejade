# Prototype Readiness

Estado de avance del prototipo de Cafe Jade basado en el objetivo del proyecto.

## Cumplido

- Sitio estatico sin Node.js obligatorio.
- Estructura de una sola pagina.
- Cinco secciones claras:
  - Inicio
  - Menu
  - Nuestra Historia
  - Eventos
  - Contacto
- Tienda convertida en accion de pedido por WhatsApp.
- Bolsa de trabajo y login interno removidos del recorrido principal.
- Boton fijo de WhatsApp.
- Base bilingue ES/EN.
- Flujo de reserva por WhatsApp.
- Flujo de pedido por WhatsApp.
- Flujo de evento privado por WhatsApp.
- Proyecto inicializado con Git.
- Base documental para Hostinger, contenido e imagenes.

- y el flujo general para turistas y clientes locales.
